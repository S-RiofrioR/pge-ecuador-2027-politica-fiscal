# PGE Ecuador 2027 - Componente Práctico 2 de Política Fiscal

Proyecto reproducible en R para el análisis cuantitativo del Presupuesto General del Estado 2027.

## Ejecución
1. Ejecutar `00_setup_proyecto.R` (una vez).
2. Ejecutar `02_SCRIPTS/99_ejecutar_todo.R`.

Ver `LEEME_ESTRUCTURA.txt` para la descripción de carpetas.
